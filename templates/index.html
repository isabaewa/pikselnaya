Как работает приложение

Изображение загружается в Django. Python декодирует его через Pillow, обрабатывает массив NumPy и сохраняет результат в PNG. Вычисления в браузере не выполняются.

Метод и варианты обновляются автоматически. Небольшие обработчики выбора только отправляют формы; все вычисления выполняет Python.

Как читать метрики и когда они появляются

Показатели появляются после сглаживания, медианной фильтрации, повышения резкости и частотной фильтрации.

Сравнение выполняется с отдельным эталоном, если он загружен, иначе — с первоначальным изображением. Назначение результата входом не меняет эталон.

Для проверки: чистое фото → шум → «Использовать результат как вход» → медианная фильтрация.

MSE — меньше лучше; PSNR — больше лучше; SSIM — ближе к 1 лучше. Совпадение: 0, ∞, 1. SSIM усредняется по окнам яркости 8×8. Без чистого эталона показатели измеряют изменение, а не восстановление.
